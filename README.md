Congressional App Challenge 2024: Secure Password Manager

A data-driven password management application built using JavaScript to handle multi-user authentication and secure credential tracking.

Core Features
  User Authentication**: Secure sign-up and log-in system that cross-references user tables and prevents duplicate registration IDs.
  Full CRUD Functionality**: Seamlessly create, read, update, and delete sensitive login credentials linked to business or website domains.
  Dynamic Record Searching**: A targeted query subsystem using interactive radio buttons to instantly filter saved logins by either company       name or user identity.
  Asynchronous Data Handling**: Engineered with asynchronous callback architectures to consistently read and update structural table storage in   real-time.

Tech Stack
  Language: JavaScript (ES5 Standard)
  Environment: Code.org App Lab Platform
  Database: Localized Key-Value Data Storage Table API

File Structure
  harshaPasswordManager.js` - Main client-side control script handling view routing, form validation, and server query calls.
